# 给 AI 助手的安装与测试说明（ComfyUI-ZH-Tag-Helper）

> 把下面整段交给你的 AI 助手（Claude Code / Codex 等），它会帮你安装插件、按需停用 Autocomplete-Plus，并做一遍功能测试。

---

你要在这台电脑的 ComfyUI 上安装并测试一个前端插件 **ComfyUI-ZH-Tag-Helper**（仓库：https://github.com/nb-diok-in-sky/ComfyUI-ZH-Tag-Helper ，目前是私有仓库）。请按顺序做，每一步做完简短汇报。

## 规则

1. 只动 `ComfyUI/custom_nodes/` 下面这两个插件文件夹，别的插件、模型、工作流、Python 环境都不要改。
2. 本插件没有 Python 依赖，**不要运行 pip install**。
3. **停用 Autocomplete-Plus 之前必须先问用户**，用户同意才做。而且不要删除，只把文件夹整个移到 `custom_nodes` 外面备份，以后想恢复移回来就行。
4. 测试时不要点「运行」生图，不要保存或覆盖用户的工作流。在提示词框里试完后，把你加的文字删掉。
5. 遇到报错先停下来，把报错原文贴给用户，不要自己猜着改插件代码。

## 步骤

### 1. 找到 ComfyUI

- 找到 ComfyUI 的安装目录（里面有 `main.py` 和 `custom_nodes`），告诉用户路径。
- 如果 ComfyUI 正在运行，请用户先把它关掉。

### 2. 下载插件

```
cd <ComfyUI>/custom_nodes
git clone https://github.com/nb-diok-in-sky/ComfyUI-ZH-Tag-Helper.git
```

- 仓库是私有的：如果提示没有权限，请用户确认仓库作者已经把他的 GitHub 账号加成协作者（Collaborator），并且已经接受邀请。登录用 Git 自带的浏览器授权，你不要替用户输入密码或 token。
- 如果连不上 GitHub，问用户有没有代理，比如 `git -c http.proxy=http://127.0.0.1:7890 clone ...`。
- 下载完检查一下：`web/tag_categories.json` 存在，大小约 2.5MB。

### 3. 处理 Autocomplete-Plus（先问用户）

- 看看 `custom_nodes` 里有没有 `ComfyUI-Autocomplete-Plus`（文件夹名可能略有不同，搜 `Autocomplete-Plus`）。
- 如果有，跟用户说清楚：两个插件同时开时，打字会弹出两个补全框；本插件已经自带中文补全，建议停用它。然后问用户是否停用。
- 用户同意：把整个文件夹移到 `<ComfyUI>/disabled_custom_nodes/`（没有就新建），不要删除。
- 用户不同意：保留它，在测试报告里注明「两个补全框同时存在」。

### 4. 启动并检查加载

- 用用户平时的方式启动 ComfyUI。
- 在启动日志里找 `ComfyUI-ZH-Tag-Helper`，确认它不在 `IMPORT FAILED` 那一行。
- 浏览器打开 ComfyUI 后，按 F5 强制刷新一次。

### 5. 功能测试（逐项打勾汇报）

先打开或新建一个带「CLIP 文本编码」节点的普通生图工作流。

- [ ] **中文补全**：在正向提示词末尾输入 `, 长发`（用中文输入法打），光标下方出现候选，第一项是「长发 long_hair」。按 ↓ 再按 Enter，插入的是 `long hair, ` 或你选中的那一项。
- [ ] **英文补全**：输入 `smi`，出现「笑 smile」等候选。按 Esc 能关掉。
- [ ] **分类面板**：点进提示词框，框旁边弹出「提示词分类」面板。每个大类第一个子类是「全部」。把光标放在文字中间，点一个标签，标签插在光标处而不是末尾，前后逗号正确。
- [ ] **面板收起**：点画布空白处，面板收起；按 Esc 也能收起。
- [ ] **违禁词**：在面板搜索框搜 `萝莉`，`loli` 这一条显示为红色「🚫违禁词·萝莉」，点击时右上角弹出警告提示。测完删掉插入的文字。
- [ ] **标签计数**：提示词框左下角显示「正向 标签 N / 30」，数字随输入变化。
- [ ] **画风图鉴窗口**：点左侧边栏的调色板图标「画风图鉴」→「打开提示词分类」，大窗口能拖顶栏移动、拖右下角缩放；关掉再打开，位置和大小保持不变。画师页是空的属于正常现象（没装可选组件）。
- [ ] **关闭自动弹出**：侧边栏取消勾选「点进提示词框时，在旁边弹出分类面板」，再点进提示词框，面板不再弹出。测完勾回去。

### 6. 汇报

用下面的格式回复用户：

```
ComfyUI 路径：
插件版本（git log -1 --oneline）：
Autocomplete-Plus：已停用并备份到 … / 用户选择保留 / 本来就没装
启动日志：正常 / 有报错（附原文）
测试结果：逐项 ✅ / ❌，❌ 的写清楚现象
浏览器和 ComfyUI 前端版本（设置 → 关于）：
其他问题或建议：
```

如果有 ❌，请用户截图，并打开浏览器开发者工具（F12 → Console），把红色报错一起贴上。
