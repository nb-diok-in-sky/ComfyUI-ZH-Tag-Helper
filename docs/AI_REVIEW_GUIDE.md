# 词库分类审查说明（给 AI 助手）

> 用法：先运行 `python tools/review_export.py` 生成清单，再把本文件整份交给 AI 助手，让它按「工作流程」一份一份做。做完后维护者运行 `python tools/review_check.py` 检查格式，人工审核通过的才会合并进词库。

---

## 你的任务

`tools/review/todo/` 里有一百多份清单，每份是同一个子类的标签（最多 200 个，按热度从高到低）。每行 4 列，用 Tab 分隔：

```
英文标签	中文	Danbooru图片数	当前分类
long_hair	长发	3608339	人物/发型
```

请你逐个检查：**这个标签放在这个分类对不对？中文翻译对不对？**只把你认为**有错**的写出来，没错的不用写。

## 工作流程

1. 按文件名顺序处理 `tools/review/todo/` 里的文件，一次只做一份。
2. 每做完一份，在 `tools/review/done/` 下建一个**同名文件**，写入你的修改建议。
3. 这一份全部都没问题，也要建同名文件，只写一行 `# 无修改`，表示这份已经查过。
4. `done/` 里已经有同名文件的，说明之前做过，跳过。
5. 做完一份就简短汇报：文件名、建议了几条。然后接着做下一份，直到全部做完或用户叫停。
6. 只能在 `tools/review/done/` 里写文件。**不要修改** `todo/`、`web/`、`tools/*.py`、`tools/*.tsv` 和其他任何文件，也不要运行生成词库的脚本。

## 输出格式（严格遵守）

每条建议一行，4 列，用 **Tab** 分隔（不是空格）：

```
英文标签	操作	新值	理由
```

`操作` 只能是下面三种之一：

| 操作 | 新值写什么 | 例子 |
| --- | --- | --- |
| `分类` | 新的 `大类/子类`，**必须是 `tools/review/categories.txt` 里已有的名字，一字不差** | `chair	分类	场景/家具·门窗	椅子是家具，不是发型` |
| `翻译` | 正确的中文，简体，**不能含 `; / , ， |` 这些符号**，要说明可以用全角括号 | `forehead	翻译	额头	原译“凸”错误` |
| `违禁` | `疑似漏标` 或 `疑似误标` | `kodomo_doushi	违禁	疑似漏标	幼童之间的性行为` |

- 理由用一句话中文写清楚，不超过 30 字。
- 同一个标签既要改分类又要改翻译，就写两行。
- 不要输出表格线、Markdown、编号或任何解释性文字，文件里只有这些行（可以有 `#` 开头的注释行）。

## 判断原则

1. **按标签的本义分**，不按字面拼写。英文里藏着别的词不算：`chair` 不是头发（hair），`houndstooth`（千鸟格）不是牙齿，`beretta_92` 是手枪不是贝雷帽，`husky` 是狗不是天空，`amusement_park` 是游乐园。
2. **没把握就不写。**宁可漏，不要乱改。能放进两个分类都说得通的（比如“脸红”算面部还是表情），**保持原样**。
3. **动作优先归动作。**“对某个部位做的动作”放表情动作，不放那个部位：
   - 梳头、扎头发、手插头发 → `表情动作/手部动作`，不是 `人物/发型`
   - 手放在他人头上、捏他人脸 → `表情动作/多人互动`
   - 拿着 / 抱着某物（`holding_xxx`） → `表情动作/拿着东西`
4. **物品看本身是什么**：鞋带是鞋子类，冰鞋是鞋子，枪套是武器相关，能量剑是武器（不是特效）。
5. **“XX背景”** → `画面/背景`；**“XX日”**（节日、纪念日） → `环境/季节·节日`；**“XX印花”** → `服饰/花纹·材质`。
6. **R18 只放明确的性内容**：性器官、性行为、体位、体液、情趣用品、色情服装、BDSM。普通的身材（肌肉、丰满）、乳沟、泳装、内衣**不是** R18。
7. **翻译**：用中文圈子里常用的说法；不要用日文汉字（`手袋`→`手套`，`水着`→`泳装`，`部屋`→`室内`）；角色名和作品名用官方中文名，拿不准就不要改。
8. **违禁标记不要动，只报告。**词库里中文前面带「🚫违禁词·」或「⚠违禁词·仅全年龄·」的是低龄相关词，这是故意标的。你只需要：
   - 看到明显低龄相关、但**没带标记**的词 → 写一行 `违禁	疑似漏标`
   - 看到带了标记、但**明显和低龄无关**的词 → 写一行 `违禁	疑似误标`
   - 不要通过“分类”或“翻译”去改动这些标记。
9. 遇到你**不愿意或不方便**看的内容（比如 R18 清单），可以跳过整份：建同名文件，写一行 `# 跳过：原因`。

## 分类说明

> 完整列表以 `tools/review/categories.txt` 为准。下面是每个分类该放什么、容易和谁混。

**人物**（人本身的属性，不含衣服）
- 人数·性别：1girl、solo、多人、性转、无人
- 身份·职业：女仆、护士、偶像、魔法少女、情侣、兄妹（指身份本身，制服放服饰）
- 种族·非人：猫娘、精灵、机器人、恶魔、兽人、拟人化、机械臂等身体改造
- 年龄 / 身材 / 皮肤：成熟、老人；肌肉、丰满、身高差；肤色、晒痕、雀斑
- 发型 / 发色 / 头发其他：发型和长度、刘海、辫子 / 头发颜色 / 其他头发描述（**发饰放服饰**）
- 面部 / 眼睛 / 瞳孔 / 眉毛·睫毛 / 嘴巴·牙齿·舌头 / 耳朵：五官的样子（**表情放表情动作**）
- 妆容·纹身：化妆、指甲油、纹身、痣、伤疤
- 胸部 / 臀部 / 手·手臂 / 腿·脚 / 身体其他部位：身体部位本身
- 翅膀·尾巴·角：翅膀、尾巴、角、光环、触手、鳍

**服饰**：风格·时尚、制服·职业装、传统服饰、泳装·紧身衣、内衣、连衣裙、上衣、外套·披风、裙子、裤子、袜子·腿饰、鞋子、手套、袖子、领口·领带·颈饰、帽子·头盔、发饰、眼镜·面具、首饰·饰品、盔甲、花纹·材质、衣着状态（湿、破、敞开、露肩、未穿某物等）

**表情动作**：表情、视线（看向哪里、朝向）、基础姿势（站坐躺、整体姿态）、手臂动作、手部动作、手势（比 V、竖大拇指、指向）、拿着东西、腿部动作、多人互动（两人以上的接触）、其他动作（吃、读、跑、打斗、自拍等）

**镜头**：景别（全身、上半身、特写、出框）、角度（俯视、仰视、第一视角、侧面）、构图（多视图、边框、倒影、剪影）、焦点（XX特写、景深、模糊）

**画面**：画质·元数据（签名、水印、打码、挑战活动）、媒介·格式（漫画、四格、封面、贴纸）、光照、背景、特效（光粒子、速度线、血、魔法阵）、文字·符号

**画风**：艺术流派·主题（写实、赛博朋克、浮世绘、Q版）、画法·媒介（线稿、水彩、厚涂、像素画、3D）、年代风格、画师·作品画风（`xxx_(style)`）、恶搞·模仿、色调（单色、XX色基调）

**环境**：季节·节日、天气·时间、天空（日月星云）、水·冰·火、植物·花

**场景**：室内、户外·自然、户外·城市、建筑、家具·门窗（家具、门窗、地板墙面）、现实地点（国家、真实地标）

**物品**：武器（含刀剑枪炮、能量武器、盾）、食物·饮料（含餐具）、动物（真实动物、宝可梦）、神话生物（龙、妖怪、天使等**生物本身**；人形的种族放人物/种族·非人）、交通工具（含机甲、坦克）、乐器·音乐、电子设备（含耳机）、运动·游戏（球、卡牌、棋）、其他物品

**R18**：裸露、走光·偷窥、性器官、性行为、体位、体液、性表情、色情服装、BDSM·束缚、情趣用品、性癖·其他

**其他**：网络梗（`xxx_(meme)`、流行梗）、作品相关（某作品专属的道具、组织、招式）、未分类（实在归不进上面任何一类的）

## 示例

```
chair	分类	场景/家具·门窗	椅子是家具，误入发型
hand_in_own_hair	分类	表情动作/手部动作	这是动作，不是发型本身
light_machine_gun	分类	物品/武器	轻机枪是武器，不是光照
floral_background	分类	画面/背景	花卉背景属于背景
gloves	翻译	手套	“手袋”是日文
completely_nude	翻译	全裸	原译“裸帽子”错误
```

不需要写的（保持原样）：

```
blush	（“脸红”放面部或表情都说得通，不改）
cleavage	（乳沟不是 R18，现在在胸部，正确）
```
